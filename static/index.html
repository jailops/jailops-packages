JailOps package repository

Signed FreeBSD 15.1+ packages for amd64 and aarch64. This is a pkg(8) repository, not a web site: configure it as described in the README.

  • jailops.pub, the public signing key
  • jailops.fingerprint, its fingerprint (sha256 of the PEM file)
  • repository URL: https://pkg.jailops.net/${ABI}/latest
